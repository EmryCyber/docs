Build a catalog of services and products your team charges for. Catalog items appear in [Invoice](/psa/invoices-quotes) line-item pickers and sync to [Stripe](/integrations/stripe) so your pricing is consistent across all billing channels.

This is the billing product catalog, not the customer-facing [Request catalog](/psa/request-catalog). Billing products can also link to QuickBooks or Zoho Books items when those workflows are enabled.

## What it does

- **Item creation** — Name, description, unit price, currency, and a free-text display unit (e.g. hour, license, user/month)
- **Stripe sync** — Push items to Stripe as Products and Prices; pull items from Stripe to keep in sync
- **Invoice picker** — When creating an invoice, pick from the catalog to auto-fill description and amount
- **Pricing consistency** — One catalog drives both PSA invoices and Stripe pricing
- **Archival** — Hide inactive items from the picker while keeping historical invoices intact

## How to add a catalog item

<Steps>
  <Step title="Open the Service Catalog">
    In the PSA module sidebar, click **Catalog**.
  </Step>
  <Step title="Click Add Item">
    Enter the name, optional SKU, description, price, currency and display unit. Long multiline descriptions can be edited in an expanded, movable editor; closing that editor keeps the draft, while the product's Save action persists it.
  </Step>
  <Step title="Save the item">
    Click **Create item**. The item is saved and marked **Not synced** (waiting to be pushed to Stripe).
  </Step>
  <Step title="Sync to Stripe">
    Click the **sync** icon next to the item. It's pushed to your Stripe account as a Product and Price; status changes to **Synced**.
  </Step>
</Steps>

## How to sync from Stripe

<Note>
  Connecting or updating Stripe queues an initial catalog sync. Use **Sync from Stripe** for a deliberate refresh or when a background dispatch did not complete. Review the import summary: unsupported or incomplete products can be skipped, and a successful connection alone does not prove every product imported.
</Note>

<Steps>
  <Step title="Click Sync from Stripe">
    At the top of the catalog list, click **Sync from Stripe**.
  </Step>
  <Step title="Confirm the import">
    Confirm the import. Regentra reads supported Stripe products and prices; it can link an exact compatible existing product rather than create a second copy.
  </Step>
  <Step title="Review imported items">
    New items are created; items with matching Stripe IDs are updated. You'll see a summary (e.g. "Imported from Stripe: 5 new, 2 updated").
  </Step>
</Steps>

## Using the catalog on invoices

When creating or editing an [Invoice](/psa/invoices-quotes), for each line item you can:

1. Click **Pick from catalog**
2. Select an item from the dropdown
3. The description and unit price auto-fill
4. Review and edit the copied description and applied rate for this invoice. These snapshots do not change the product's default price or a customer's agreement.

If an item is later archived, historical invoices keep referencing it; it just won't appear in the picker for new invoices.

## Pricing and currency changes

Products and agreements can retain their links while using a customer-specific negotiated price. The picker shows the applied invoice rate where it differs from the catalog default. Duplicating a product creates a separate editable record rather than changing existing contracts.

If you edit a catalog item's unit price or currency:

- Future invoices use the new value immediately
- Existing invoices retain the price at time of generation
- The next Stripe sync creates a new Stripe Price (the old price remains on historical invoices)

Stripe-backed line items are validated against the actual Stripe Price and currency. Zero-decimal currencies require whole-unit pricing. Do not treat a Stripe Price identifier as proof that an edited local amount is already synchronized.

## CSV import and export

Use product CSV import to preview each row before committing. Map name, SKU, description, price, currency and unit, then review matches, warnings and errors. SKU matching ignores case; conflicting or ambiguous matches need attention. Import limits apply before parsing oversized files.

Export products to move or audit catalog data. Full descriptions retain line breaks. An import does not overwrite historical invoices or agreement prices, and linked Stripe prices have additional protections against conflicting price updates.

## Accounting item links

QuickBooks and Zoho Books can import or link sellable items to products. A product-master setting determines which side owns changes; differences that conflict with local edits go to review. QuickBooks hourly product sync is off until an administrator enables it.

Using product-specific accounting items on invoice lines is a separate opt-in from importing products. Sending Regentra product changes to Zoho is another opt-in and requires the appropriate connection permissions. Xero invoices use the mapped sales account; this does not imply Xero product-catalog synchronization.

## Archiving items

Click **Archive** to hide an item from the invoice picker. The item is marked Archived and won't appear in new invoices. Historical invoices continue to reference it.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I have different prices for different customers?">
    A product has a default price. Agreements and invoice lines can carry a different negotiated price without changing that default or historical invoices.
  </Accordion>
  <Accordion title="What currencies are supported?">
    Any ISO 4217 currency code (USD, EUR, GBP, etc.). Enter the 3-letter code when creating or editing an item.
  </Accordion>
  <Accordion title="Can I import products from Stripe?">
    Yes. **Sync from Stripe** reads supported products/prices, updates provider-linked records and can link exact compatible existing products. Review skipped items and conflicts; a sync is not a guarantee every Stripe price is suitable for an invoice line.
  </Accordion>
  <Accordion title="What if I archive a catalog item by mistake?">
    Create a new item with the same details, or contact support to restore the archived item.
  </Accordion>
</AccordionGroup>
